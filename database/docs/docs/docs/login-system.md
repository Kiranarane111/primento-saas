# Login & Authentication System

## User Roles

1. Super Admin
2. Admin
3. Site Manager
4. Supervisor
5. Store Incharge
6. Client
7. Employee

## Login Methods

- Mobile Number + OTP
- Email + Password

## Security Features

- Role Based Access Control
- Password Reset
- OTP Verification
- Session Management
- Activity Logs

## Dashboard Access

Each role should see a customized dashboard after login.
