# Primento SaaS 🚀

Smart Facility Management & Workforce Automation System

## Features
- Employee Attendance System
- Payroll Automation
- CRM & Lead Management
- Role-based Dashboard
- SaaS Subscription System

- Backend: Node.js + Express
- Database: MongoDB

Frontend → Backend API → MongoDB → Payment System
